## 📖 About the Project

**Kaksha Mitra** is an educational web application developed to make learning easier for students by providing **chapter-wise PDF solutions** for the **Class 8 Ganita Prakash** textbook.

The website focuses on simplicity, speed, and accessibility, allowing students to easily search, view, and download chapter solutions on both desktop and mobile devices.

---

## ✨ Features

* 📚 Chapter-wise PDF Solutions
* 👁️ View PDFs directly in the browser
* 📥 Download PDF files
* 🔍 Live Chapter Search
* 📱 Mobile-First Responsive Design
* 🎨 Clean and Modern User Interface
* ⚡ Fast Loading Performance
* 🖥️ Cross-Browser Compatibility
* 📖 Simple Navigation
* 💙 Student-Friendly Experience

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Coderush2004/kaksha-mitra.git
```

### Navigate to the Project

```bash
cd kaksha-mitra
```

### Run the Website

Simply open **index.html** in your preferred web browser.

No installation or server setup is required.
